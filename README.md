# VitaPet — Clínica Veterinária Especializada

> Site de clínica veterinária

## 📌 Sobre o Projeto

Site modelo de clínica veterinária com serviços, especialidades e cuidados, além de agendamento de consultas.

## ✨ Funcionalidades

- Serviços veterinários
- Especialidades e cuidados
- Seção sobre a clínica
- Agendamento de consultas
- Design acolhedor e responsivo

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Descrição |
|------------|-----------|
| **HTML5** | Estrutura semântica e acessível da página |
| **CSS3** | Estilo visual, layout e responsividade |
| **JavaScript** | Interatividade, manipulação do DOM e lógica do cliente |

## 🚀 Como Executar

1. Clone este repositório:
   ```bash
   git clone https://github.com/mariniltonquintanilha-hash/Veterinaria.git
   ```
2. Abra o arquivo `index.html` no navegador.

## 📁 Estrutura do Projeto

```
├── index.html    → Página principal
├── style.css     → Estilos e responsividade
└── script.js     → Interatividade e lógica
```
